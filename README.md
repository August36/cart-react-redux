README.me

Smart phone shop - School project

Features
- Browse smart phones from DummyJSON API
- view individual phone in a modal
- update quantities in the cart
- remove products from the cart
- calculate the cart total
- checkout page
- client side routing with React Router
- Global state management with Redux Toolkit

Technologies
- React
- Redux Toolkit
- Tailwind CSS

Installation
Clone the repository:
- git clone https://github.com/August36/cart-react-redux.git

navigate to project folder:
- cd cart-react-redux

install dependencies:
- npm install

Running the project
- npm run dev
